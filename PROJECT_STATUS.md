# Інструкція проекту: Monitoring System

Цей файл є живим документом для синхронізації контексту між сесіями. Він містить структуру, ТЗ та поточний стан розробки.

## 🏗 Структура проекту
- `main.py` — Основний файл Flask-додатку. Містить API, логіку маршрутизації та ініціалізацію БД.
- `new_database.db` — Поточна робоча база даних SQLite.
- `database.db` — Стара версія БД.
- `static/` — Статичні файли (uploads, reports, sw.js).
- `templates/` — HTML шаблони (index, admin).
- `venv/` — Віртуальне середовище.

## 🎯 Основне технічне завдання (ТЗ)
Веб-додаток для моніторингу об'єктів (CRUD), фотофіксації, обліку робіт/годин/витрат, генерації звітів та їх розсилки.

## ⚙️ Технологічний стек
- **Backend:** Python 3.10+, Flask, SQLite.
- **Frontend:** Vanilla HTML/CSS/JS, Service Worker (PWA).
- **Інтеграції:** SMTP (Gmail) для відправки пошти, html2pdf.js (генерація звітів на клієнті).
